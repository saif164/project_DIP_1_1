## 1. نظرة عامة على مكدس التقنيات

تم اختيار حزمة التقنيات البرمجية لهذا المشروع بعناية فائقة لتحقيق متطلبات الأداء اللحظي الفائق (**Real-Time High Performance $\ge 30-60\text{ FPS}$**)، مع الحفاظ على أقل استهلاك لموارد المعالج (CPU Consumption $< 15\%$)، وإمكانية التشغيل على أجهزة الحواسيب العادية وكاميرات الويب التجارية دون الحاجة لعتاد إضافي باهظ الثمن.

```
+-----------------------------------------------------------------------+
|                       🖥️ Presentation Layer (UI)                      |
|            Python Tkinter + Dark Glassmorphic Canvas + Pillow         |
+-----------------------------------------------------------------------+
                                   ▲
                                   │ (Thread-Safe Mutex Locks)
                                   ▼
+-----------------------------------------------------------------------+
|                    🧠 Core Logic & State Machine                      |
|         Latching FSM + Deadband Leash Filter + Affine Matrix          |
+-----------------------------------------------------------------------+
                                   ▲
                                   │ (Extracted 3D Landmarks)
                                   ▼
+-----------------------------------------------------------------------+
|                   👁️ Computer Vision & DIP Pipeline                  |
|          OpenCV (cv2) + MediaPipe Tasks (Face & Hand Landmark)        |
+-----------------------------------------------------------------------+
                                   ▲
                                   │ (Real-Time I/O & CRUD)
                                   ▼
+-----------------------------------------------------------------------+
|                   🗄️ Persistence & Database Layer                     |
|           JSON Calibration Cache + SQLite3 Relational DB (3NF)         |
+-----------------------------------------------------------------------+
```

## 2. لغة البرمجة وبيئة التشغيل الأساسية

### 🐍 **Python 3.10+ / 3.11+ / 3.13**
* **الدور في النظام:** اللغة الأساسية المستخدمة في بناء كامل المنظومة البرمجية من خوارزميات معالجة الصور، التحويلات الهندسية، آلة الحالات، واجهة المستخدم، ومولدات التقارير.
* **سبب الاختيار:**
  - التكامل الأصلي (Native Integration) مع أحدث مكتبات الرؤية الحاسوبية والتعلم الآلي (MediaPipe, OpenCV, NumPy).
  - دعم أصلي لبرمجة التزامن وتعدد الخيوط (`threading`, `queue`).
  - سرعة التطوير الهندسي وقابلية الصيانة والتوسع (High Maintainability).
  - توافق شامل مع بيئات أنظمة التشغيل (Cross-Platform: Windows, Linux, macOS).

## 3. مكتبات الرؤية الحاسوبية ومعالجة الصور

### 👁️ **Google MediaPipe Tasks API (`mediapipe >= 0.10.9`)**
* **النماذج المستخدمة:**
  1. `face_landmarker.task` (478 نقطة ثلاثية الأبعاد 3D Facial Landmarks).
  2. `hand_landmarker.task` (21 نقطة للمفصل اليدوي 3D Hand Landmarks).
* **الدور في النظام:**
  - استخراج إحداثيات طرف الأنف (Landmark #1 / #4) للتحكم الدقيق في المؤشر.
  - استخراج إحداثيات الجفون والعيون وحساب مقياس انفتاح العين (**Eye Aspect Ratio - EAR**) لمنع الكتابة أثناء الرمش أو النعاس.
  - استخراج نقاط الوجه المرجعية وتقدير زوايا ميلان وتوجيه الرأس (**Head Pose: Yaw, Pitch, Roll**).
  - تصنيف إيماءات اليد (قبضة اليد للإيقاف المؤقت، كف اليد للاستئناف، والأصابع لقفل الصفوف).
* **سبب الاختيار:**
  - يعمل بتقنية شبكات التلافيف العميقة الخفيفة (MobileNet/BlazeFace) المحسنة للتشغيل الفوري على المعالج العادي (CPU) دون الحاجة لبطاقة رسوميات خارجية (GPU).
  - دقة متناهية مقارنة بخوارزميات Haar Cascades أو Dlib القديمة.

### 📷 **OpenCV (`opencv-python >= 4.8.0`)**
* **الدور في النظام:**
  - فتح وتدفق إطارات كاميرا الويب اللحظية عبر `cv2.VideoCapture`.
  - معالجة المصفوفات اللونية (تحويل BGR إلى RGB، وتطبيق المرآة الأفقية `cv2.flip`).
  - قراءة أبعاد الإطار والتحكم في معدل الإطارات (FPS).

## 4. مكتبات الحسابات الرياضية والتحويلات الهندسية

### 🔢 **NumPy (`numpy >= 1.24.0`)**
* **الدور في النظام:**
  - إجراء العمليات المتجهية الخطية (Vector Operations) على مصفوفات الإحداثيات بسرعة عالية بلغة C.
  - حل معادلات المربعات الصغرى التآلفية (**9-Point Affine Transformation Matrix**) عبر `np.linalg.lstsq`.
  - تطبيق عمليات القص والتقييد الآمن للإحداثيات عبر `np.clip`.

### 📐 **SciPy (`scipy >= 1.10.0`)** *(اختياري / مدعوم)*
* **الدور في النظام:** الحسابات الإحصائية المتقدمة وحساب التباعد وحلول المصفوفات المعقدة.

## 5. أطر عمل واجهات المستخدم والتزامن

### 🖼️ **Python Tkinter (Native Standard Library)**
* **الدور في النظام:** بناء واجهة المستخدم الرسومية الكاملة (GUI) لنظام الكيبورد، ولوحة التحكم، ونافذة المعايرة التفاعلية 9 نقاط (`calibration_ui.py`).
* **سبب الاختيار:**
  - مكتبة أصلية مدمجة مع بايثون (Zero External GUI Dependencies).
  - استهلاك معدوم للذاكرة مقارنة بالأطر الثقيلة كـ Electron أو Qt.
  - إمكانية الرسم عالي التردد عبر `tk.Canvas` لعرض مؤشر الليزر وحلقة التثبيت الدائرية (Circular Dwell Ring).

### 🎨 **Pillow / PIL (`pillow >= 10.0.0`)**
* **الدور في النظام:** تحويل إطارات الفيديو المعالجة من مصفوفات NumPy إلى صيغ رسومية متوافقة مع Tkinter (`ImageTk.PhotoImage`) لعرض بث الكاميرا المصغر اللحظي (Picture-in-Picture PIP).

### 🧵 **Python Threading & Synchronization (`threading.Lock`, `threading.Thread`)**
* **الدور في النظام:**
  - فصل خيط المعالجة الرؤيوية الثقيل (**Worker Thread**) عن خيط الواجهة الرسومية (**GUI Main Thread**) لضمان سلاسة الواجهة بمعدل 60Hz دون أي تجميد (Lag-Free UI).
  - حماية المتغيرات المشتركة ونتائج التتبع (`TrackingResult`) باستخدام أقفال الاستبعاد المتبادل (**Mutex Locks**).

## 6. منظومة إدارة البيانات وقواعد البيانات

### 📄 **JSON (JavaScript Object Notation)**
* **الملف:** `config/calibration.json`
* **الدور:** تخزين خفيف الوزن وفوري لمعاملات المعايرة الحالية للمستخدم (مصفوفة التحويل التآلفي، المنطقة الميتة، الحساسية) للوصول المباشر بزمن استجابة 0ms.

### 🗄️ **SQLite 3 & SQL DDL (`backend/database_schema.sql`)**
* **الدور:** قاعدة بيانات علائقية كاملة توفر المعيار القياسي **3NF** لإدارة ملفات المرضى، جلسات الكتابة، معدلات السرعة (WPM)، وسجلات الإجهاد البصري والتحذيرات الفسيولوجية.

## 10. دليل تثبيت البيئة والمتطلبات

### 1. المتطلبات الأساسية:
- نظام تشغيل: Windows 10/11, Linux (Ubuntu 20.04+), macOS.
- إصدار بايثون: Python 3.10 أو أحدث.
- كاميرا ويب قياسية (720p أو 1080p).

### 2. خطوات التثبيت:
```bash
# الانتقال لمجلد المشروع
cd project_DIP_1_1

# إنشاء وتفعيل بيئة افتراضية (موصى به)
python -m venv venv
venv\Scripts\activate      # على ويندوز
# source venv/bin/activate # على لينكس/ماك

# تثبيت الحزم المطلوبة
pip install -r requirements.txt
```

